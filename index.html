Application locale hors ligne

Générateur de charte du bien vivre ensemble

Construisez une charte claire, un poster de service et un PDF imprimé directement depuis votre navigateur, sans serveur et sans envoi de données.

1

Mise en page du document

Choisissez la palette et la police appliquées aux PDF produits.

2

Informations du service

Renseignez les informations d'identification qui apparaîtront dans les documents.

Aucun logo de service importé

Le logo du service apparaîtra à droite du logo Douanes dans la prévisualisation, le PDF et le JSON.

Cette option n'agit que sur le document A4. Le poster A3 reste synthétique.

3

Choix des valeurs

Sélectionnez exactement 3 valeurs, puis choisissez leur ordre de rendu. Le glisser-déposer reste disponible.

0 valeurs sélectionnées sur 3

Valeurs disponibles

9 valeurs chargées au démarrage.

Valeurs retenues pour la charte

Les trois valeurs choisies apparaissent dans l'ordre utilisé par les rendus.

4

Valeurs

Renseignez les règles, gestes ou engagements concrets associés aux trois valeurs.

5

Engagements

Complétez les engagements communs selon les trois points de vue.

6

Sauvegardes et export

Le brouillon reste local. Le ZIP d'échange est nommé avec le service et la version pour faciliter le travail collaboratif.

ZIP d'échange : il contient le JSON complet, les versions HTML A4/A3, un manifeste et une notice. Dans Chrome/Edge, vous pouvez choisir l'emplacement du ZIP ; sinon il est placé dans les téléchargements.

PDF : l'application télécharge automatiquement le fichier A4 ou A3 demandé dans le dossier de téléchargements du navigateur.
